## Часть 2. 3D Gallery (GLB)

Интерактивная веб-галерея для предпросмотра 3D-моделей (формат GLB) с возможностью загрузки своих моделей, просмотра превью и ручного вращения.

### Функции интерфейса

- **Список моделей:** сетка карточек с интерактивными 3D-превью
- **Загрузка файлов:** можно добавить свой `.glb` файл (хранится в IndexedDB браузера)
- **Детальный просмотр:** вращение мышью, зум кнопками, быстрая смена ракурса (спереди/сзади/слева/справа)
- **Удаление:** пользовательские модели можно удалить

### Структура проекта

```
project-root/
├── index.html           // Часть 1: Задачи по JavaScript
├── index2.html          // Часть 2: Главная страница (галерея)
├── detail.html          // Страница просмотра модели
├── app.js               // Логика галереи
├── detail.js            // Управление камерой
├── idb.js               // Работа с IndexedDB
├── styles.css           // Вёрстка
├── moduls/              // Предустановленные .glb модели
│     ├── Big Tree.glb
│     ├── Palm Tree.glb
│     └── Range Rover.glb
└── README.md
```

### Запуск

1. Открыть через локальный сервер
2. VS Code: расширение Live Server → "Go Live"
3. Перейти на `http://localhost:5500/index2.html`

### Технологии

- Three.js (модули через importmap)
- GLTFLoader для загрузки .glb
- IndexedDB (idb.js) для хранения пользовательских моделей
- CSS без фреймворков
