## Теоретическая часть

### HTML
HTML (HyperText Markup Language) — язык разметки, с помощью которого описывается содержимое веб-страницы: текстовые поля, таблицы, кнопки, заголовки, ссылки и т.д.

**Основные HTML-элементы, использованные в работе:**
- Заголовки (`<h1>`-`<h6>`)
- Кнопки (`<button>`)
- Контейнеры (`<div>`)
- Атрибуты (`id`, `class`)

### CSS
CSS (Cascading Style Sheets) — каскадные таблицы стилей, позволяющие кастомизировать отображение HTML-элементов на странице.

**Типы селекторов:**
- Селекторы по элементу (`h1`, `button`)
- Селекторы по идентификатору (`#my_custom_element`)
- Селекторы по классу (`.my-class`)

**Псевдоклассы:**
- `:hover` — состояние при наведении курсора
- `:active` — состояние при активации (нажатии)
