## Решённые задачи

### 1.7 `isEqualObj()` (1 уровень)

Сравнивает два объекта через `JSON.stringify` и возвращает `true`, если они идентичны.

### 2.7 `sumDiagonals()` (2 уровень)

Принимает квадратную матрицу, возвращает сумму элементов главной и побочной диагоналей. Для нечётного размера центральный элемент не учитывается дважды.

### 3.7 `plainify()` (3 уровень)

Рекурсивно преобразует вложенный объект в плоский, где ключи вложенных уровней соединяются через точку. Массивы не сплющиваются.

## Вывод

В ходе выполнения работы были реализованы три функции разного уровня сложности: сравнение объектов (`isEqualObj`), работа с матрицами (`sumDiagonals`) и рекурсивное преобразование объектов (`plainify`). Все функции покрыты тестами, которые проверяют граничные случаи (пустые объекты, матрицы разного размера, глубокая вложенность).
