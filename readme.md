## Теоретическая часть

### Node.js
Node.js — программная платформа, основанная на движке V8 (Google Chrome), позволяющая выполнять JavaScript код вне браузера — на сервере или локальном компьютере. В отличие от браузерного JS, Node.js предоставляет доступ к файловой системе, сети и другим возможностям операционной системы.

### npm (Node Package Manager)
npm — стандартный пакетный менеджер для Node.js. С его помощью можно устанавливать сторонние библиотеки и управлять зависимостями проекта. Все установленные пакеты сохраняются в папку `node_modules`, а информация о них — в файлах `package.json` и `package-lock.json`.

### package.json
Файл, содержащий метаинформацию о проекте: название, версию, описание, список зависимостей, скрипты для запуска. Является основным конфигурационным файлом Node.js-проекта.

### Bootstrap
Популярный CSS-фреймворк, предоставляющий готовые компоненты для быстрой верстки адаптивных интерфейсов. В работе использовался Bootstrap 5, установленный через npm.

### Компонентный подход
Архитектурный паттерн, при котором интерфейс разбивается на независимые, переиспользуемые блоки — компоненты. Каждый компонент отвечает за свою часть интерфейса и может быть переиспользован на разных страницах.

## Ход выполнения

### 1. Установка Node.js и инициализация проекта
- Установлен Node.js (рекомендуется использовать nvm для Windows или Homebrew для macOS)
- Создана папка проекта
- Выполнена команда `npm init` для создания `package.json`

### 2. Структура проекта
Создана следующая структура директорий и файлов:
├── node_modules/ # Установленные пакеты
├── .gitignore # Исключения для Git
├── package-lock.json # Дерево зависимостей
├── package.json # Конфигурация проекта
├── index.html # Точка входа (корневой элемент)
├── main.js # Главный скрипт (роутинг)
├── pages/ # Страницы приложения
│ └── main/ # Главная страница
│ │ └── index.js
│ └── product/ # Страница продукта
│ └── index.js
└── components/ # Переиспользуемые компоненты
├── button/ # Компонент кнопки
├── back-button/ # Кнопка "Назад"
├── product-card/ # Карточка товара
└── product/ # Детальная карточка товара

### 3. Подключение Bootstrap
Выполнена установка Bootstrap через npm:
```bash
npm i bootstrap
```
В файл `index.html` добавлены ссылки на CSS и JS Bootstrap:
```html
<link rel="stylesheet" href="node_modules/bootstrap/dist/css/bootstrap.min.css">
<script src="node_modules/bootstrap/dist/js/bootstrap.bundle.min.js"></script>
```

### 4. Создание корневого элемента
В `index.html` добавлен div с id="root" — точка входа для всех страниц:
```html
<div id="root"></div>
<script src="main.js" type="module"></script>
```

### 5. Реализация компонентов
Компонент ButtonComponent (`components/button/index.js`):
* Отвечает за отрисовку кнопки
* Принимает данные и обработчик клика

Компонент ProductCardComponent (`components/product-card/index.js`):
* Отрисовывает карточку товара с изображением, заголовком, описанием
* Содержит кнопку для перехода на страницу деталей
* Поддерживает передачу обработчика события

Компонент BackButtonComponent (`components/back-button/index.js`):
* Кнопка возврата на главную страницу

Компонент ProductComponent (`components/product/index.js`):
* Отрисовывает детальную информацию о товаре в горизонтальной карточке

### 6. Реализация страниц
Главная страница (`pages/main/index.js`):
* Создает контейнер для карточек (flexbox)
* Получает массив данных о товарах
* Для каждого товара создает компонент ProductCardComponent
* При клике на карточку переходит на страницу продукта

Страница продукта (`pages/product/index.js`):
* Принимает id выбранного товара
* Отображает детальную информацию о товаре
* Содержит кнопку возврата на главную страницу

### 7. Роутинг и навигация
В файле `main.js` реализована инициализация главной страницы:
```js
import {MainPage} from "./pages/main/index.js";

const root = document.getElementById('root');
const mainPage = new MainPage(root);
mainPage.render();
```
Переход между страницами осуществляется через вызов конструктора нужной страницы с последующим вызовом метода `render()`.

### 8. Выполнение индивидуального задания
**Вариант:** собаки + аккордеон

1. **Тема "Собаки"**:
   - На главной странице отображаются карточки с 4 породами собак (Хаски, Сиба-ину, Золотистый ретривер, Английская овчарка)
   - Каждая карточка содержит изображение, название породы и краткое описание

2. **Компонент "Аккордеон"**:
   - Создан компонент `AccordionComponent`
   - Добавлен на страницу детального просмотра породы
   - Содержит 3 раздела: "Характеристики", "Особенности породы", "Интересные факты"
   - Реализована возможность сворачивания/разворачивания секций

3. **Результат**: Получено двухстраничное приложение с компонентом аккордеон, стилизованное под тему "Собаки".
