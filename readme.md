# Программирование сетевых приложений (ПСП)

**Группа:** ИУ5Ц-64Б

**Семестр:** 6

**Предмет:** Программирование сетевых приложений

## О репозитории
Данный репозиторий создан для выполнения лабораторных работ в 6-м семестре.
Каждая лабораторная работа находится в отдельной ветке.

## Ветки
- `feature/calculator-ui` — Лабораторная работа №1 (Калькулятор. HTML/CSS)
- `project/my-site` — Лабораторная работа №2 (Калькулятор. JS)
- `feature/node-app-structure` — Лабораторная работа №3 (Простое веб-приложение. Верстка)
