## Функции интерфейса

- **Список моделей:** сетка карточек с интерактивными 3D-превью (автовращение)
- **Загрузка файлов:** можно добавить свой `.glb` файл через кнопку в хедере (хранится в IndexedDB браузера)
- **Детальный просмотр:** вращение мышью (OrbitControls), зум кнопками +/–, быстрая смена ракурса (спереди/сзади/слева/справа)
- **Удаление:** пользовательские модели можно удалить

## Структура проекта

```
project-root/
├── index2.html          // Главная страница (галерея)
├── detail.html          // Страница просмотра модели
├── app.js               // Логика галереи (модули)
├── detail.js            // Управление камерой и просмотр
├── idb.js               // Работа с IndexedDB
├── styles.css           // Вёрстка
├── moduls/              // Предустановленные .glb модели
│     ├── Big Tree.glb
│     ├── Palm Tree.glb
│     └── Range Rover.glb
└── readme.md
```

## Запуск

1. Открыть через локальный сервер (например, Live Server в VS Code)
2. Перейти на `http://localhost:5500/index2.html`

---

## Технологии

- **Three.js** (модули через importmap)
- **GLTFLoader** для загрузки .glb
- **OrbitControls** для вращения камеры
- **IndexedDB** (idb.js) для хранения пользовательских моделей
- Чистый CSS, без фреймворков

## Вывод

В ходе выполнения работы была разработана интерактивная веб-галерея для просмотра 3D-моделей формата GLB. Реализована сетка карточек с автоматически вращающимися превью, загрузка пользовательских моделей через IndexedDB, а также детальный просмотр с управлением камерой (OrbitControls, зум, ракурсы). Модели автоматически центрируются по основанию. Проект построен на Three.js с модульной архитектурой.
