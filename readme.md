## Теоретическая часть

### JavaScript
JavaScript — язык программирования, который служит основным инструментом для описания логики и интерактивности веб-страниц. В данной работе с помощью JS мы программируем кнопки калькулятора, чтобы они выполняли математические действия.

**Подключение JavaScript к HTML:**
Существует два основных способа:
- Встроенный скрипт — код пишется внутри тега `<script>` в HTML-файле.
- Внешний файл — код хранится в отдельном файле с расширением .js и подключается через атрибут src. Этот способ является более предпочтительным, так как разделяет структуру и логику.

**Обработчики событий**
Это функции, которые вызываются при совершении какого-либо действия пользователя (события). В данной работе основное событие — `click` (нажатие на кнопку).

**Способы задания обработчиков:**
- Через атрибут HTML (`onclick="..."`) — не рекомендуется для сложной логики.
- Через свойство элемента (`element.onclick = function() {...}`).
- Через метод addEventListener (`element.addEventListener('click', function() {...})`) — современный стандарт, позволяющий назначать несколько обработчиков.

### 2. Разработка логики на JavaScript

**Инициализация переменных:**
Вся логика обернута в событие window.onload, чтобы гарантировать загрузку DOM-дерева перед выполнением скрипта. Были объявлены переменные для хранения:
- `a` — первое число (строка);
- `b` — второе число (строка);
- `selectedOperation` — выбранная математическая операция;
- `expressionResult` — результат вычисления.

**Получение доступа к элементам**
Для работы с интерфейсом были получены ссылки на ключевые элементы:
- `outputElement` — элемент дисплея (`#result`), куда выводится результат.
- `digitButtons` — все кнопки с цифрами и точкой, отобранные с помощью CSS-селектора [`id ^= "btn_digit_"`].

**Реализация функций**
1. Функция `onDigitButtonClicked(digit)`: отвечает за формирование числа при нажатии на цифровые кнопки. Если операция не выбрана, цифра добавляется к первому числу `a`, иначе — ко второму `b`. Также реализована защита от ввода нескольких точек.
2. Обработчики для цифровых кнопок: для каждой кнопки из `digitButtons` назначается обработчик `onclick`, который вызывает `onDigitButtonClicked` с текстом нажатой кнопки.
3. Обработчики для кнопок операций: при нажатии на кнопки (`+`, `-`, `x`, `/`) в переменную `selectedOperation` сохраняется соответствующий символ, при условии, что первое число a не пустое.
4. Кнопка очистки (C): обработчик сбрасывает значения всех переменных и устанавливает на дисплее 0.
5. Кнопка равно (=): обработчик проверяет наличие обоих чисел и выбранной операции. Используя конструкцию `switch` в зависимости от значения `selectedOperation`, производится вычисление. Результат сохраняется в переменную a (преобразованный в строку), а b и `selectedOperation` сбрасываются для следующего вычисления.
